# Why water injection was not kept in production engines

Literature research only. This note tests commonly offered reasons automakers did not continue water injection (or water-methanol / ADI) in production vehicle engines after limited production or near-production use.

The checked report is [why-not-adopted.md](why-not-adopted.md). Prefer the verification section over the Hermes draft text at the top of that file.

Oil-company or political-pressure claims are reported only when a source documents them. This check found none.
