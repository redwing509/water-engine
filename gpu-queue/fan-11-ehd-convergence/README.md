# fan-11-ehd-convergence — queue item #11 (Fan EHD mesh + time-step convergence)

Status: **ready, waiting for James's HF hardware**. Built and smoke-tested on mail (see `SMOKE_TEST.md`).

## Honest hardware note — this is a CPU job
The solver is a custom OpenFOAM Foundation **4.1** application (buoyantBoussinesqPimpleEHDFoam). There is
**no GPU code path** (no petsc4Foam/AmgX/OGL for OF 4.1, and the meshes are 4.7k–75k cells, far too small
for a GPU to help). Expected GPU speedup: **~1.0x (none)**. What the job needs is CPU cores: the five runs are
independent, so wall time = the slowest run.

| HF flavor | vCPU / RAM | expected wall time | approx. cost* |
|---|---|---|---|
| cpu-performance (recommended) | 32 / 256 GB | ~8 h | ~$15 |
| cpu-xl | 16 / 124 GB | ~10–12 h | ~$12 |
| any GPU flavor | GPU unused | same as its vCPU count | wasted |
\* HF list prices seen 2026-10-24 ($1.90/h, $1.00/h); paid compute = James's decision. Alternative at $0:
run it on mail if James raises the Fan policy above 2 cores/4 GB (it needs ~21 cores for ~8 h, or 8 cores for ~2 days).

## Results return path
`push_results.sh` pushes `results/hf/<RUN_ID>/` (summary.json/md, per-case run.status, log tails, checkMesh,
final-time fields + mesh tarball, solver sha256, hardware.txt) to a **new branch**
`hf-results/<RUN_ID>` of redwing509/solid-state-fan-project. It never pushes to main or simulation-results
and never force-pushes; Grok Bot/peer review then merges into `simulation-results` per Fan rules.
Token: HF Jobs secret **GH_TOKEN** = fine-grained GitHub PAT, repo `redwing509/solid-state-fan-project` only,
Contents: read & write. Read from the environment only (GIT_ASKPASS), never written to files/URLs/logs.
If GH_TOKEN is absent the job still runs and leaves results in the job logs/`/out` (PUSH=0).
